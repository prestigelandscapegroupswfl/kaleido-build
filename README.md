# KALEIDO — Madnox Build

Kodi 21.3 (Omega) build package: Madnox.Redux fork (skin.kaleido) with the animated-art engine — animated posters, true animated fanart, movie character art — plus all dependencies, Artwork Dump pre-configured, and the Google Drive library source. KALEIDO is the default skin at startup.

Download `Kaleido-Madnox-Build-v1.zip`, unzip, and follow the INSTALL-GUIDE.md inside (numbered folders, 9 steps).
